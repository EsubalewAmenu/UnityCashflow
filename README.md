# Cashflow Unity

Unity 2D rebuild of the existing JavaScript Cashflow game. Open this folder from Unity Hub using **Add > Add project from disk**, then open any empty scene and press Play.

The game builds its UI in code and includes:

- Profession and dream selection
- 24-space Rat Race with animated-position token, payday, deals, doodads, charity, baby, market and downsizing events
- Passive-income financial statement and automatic Rat Race escape
- 24-space Fast Track with cashflow days, deals, hazards and dream victory
